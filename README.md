# Star Dodger

A small 2D browser game made with plain HTML, CSS, and JavaScript.

## How to play

Open `index.html` in a browser, click **Start game**, and dodge the falling meteors with the left/right arrow keys or A/D. On a phone or tablet, use the on-screen buttons.

## Play on GitHub Pages

In the repository settings, open **Pages**, choose the `main` branch as the deployment source, and save. GitHub will provide a public game link.
